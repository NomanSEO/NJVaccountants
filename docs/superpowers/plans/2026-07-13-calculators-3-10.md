# Calculators 3–10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans task-by-task.

**Goal:** Deliver calculators 3–10 as listed, testable routes with accessible result data, exports, and SEO content.

**Architecture:** Keep formulas in pure TypeScript under `src/lib`; pair each route with a focused client component. Reuse shared actions, formatting, charts, and the existing calculator page shell.

## Tasks

1. Create and test a reusable loan-schedule engine supporting repayment,
   interest-only, deferred, balloon, fees, monthly/yearly displays, and CSV
   rows. Expose `calculateLoanSchedule(input): LoanResult`.
2. Build Car Loan, Loan, and Personal Loan client components on that engine;
   create their routes, schedules, charts, exports, SEO content, and cards.
3. Create and test investment-growth utilities for APY/CD, recurring
   contributions, scenario projections, and retirement withdrawal estimates.
4. Build CD, Investment, and Retirement components/routes with required
   compounding/frequency/scenario controls, yearly tables, charts, exports,
   SEO, and cards.
5. Create and test Roth IRA 2026 rule data and phase-out/projection utilities.
6. Build the Roth IRA component/route with filing-status eligibility,
   contribution timing, catch-up, Roth/traditional comparison, chart/table,
   export, SEO, and card.
7. Create and test a 2026 U.S. paycheck engine for annualized federal tax,
   FICA/Medicare, pre/post-tax deductions, pay frequencies, and a separately
   labeled state/local estimate input layer.
8. Build Salary Paycheck component/route with required pay frequencies,
   status/dependant/allowance fields, compensation/deduction fields, results,
   chart/table/export/SEO/card.
9. Verify every new route, full Vitest suite, `npx tsc --noEmit`, scoped lint,
   and `pnpm build`; fix findings and update the calculator directory.

## Global Constraints

- Do not persist financial inputs; use local print/share/CSV actions.
- Support USD/GBP/EUR where answered; USD is default.
- Every calculator includes a table, accessible chart equivalent, SEO copy,
  existing CTA, and estimate wording.
- Tax/payroll rule data must be isolated by tax year and source.
